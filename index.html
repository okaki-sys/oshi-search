内容
YouTube の再生回数や「切り抜き(YouTube検索)」を使うには、Google の APIキー(無料)が必要です
Holodex は再生回数を持っていないため、YouTube 公式 API から取得します。設定しない場合、再生回数順は Twitch の結果にだけ効きます。
  1. https://console.cloud.google.com/ に Google アカウントでログインし、プロジェクトを新規作成する
  2. 「APIとサービス」→「ライブラリ」で「YouTube Data API v3」を検索して「有効にする」
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」で作成し、表示されたキーをコピー
Twitch を検索するには、Twitch のキー(無料)が必要です
  1. Twitch にログインし、設定の「セキュリティとプライバシー」で二段階認証を有効にする(アプリ登録に必要)
  2. https://dev.twitch.tv/console を開き、「アプリケーションを登録」を押す
  3. 名前は自由、OAuthリダイレクトURL は http://localhost 、カテゴリは Application Integration、クライアントのタイプは「機密」を選んで作成
  4. 作成したアプリの「管理」を開き、クライアントID をコピー。「新しい秘密」を押してクライアントシークレットもコピー
